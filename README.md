## Deskripsi

Tugas ini dibuat untuk memenuhi tugas mata kuliah Kriptografi.
Terdapat tiga aplikasi sistem cipher yang dibuat menggunakan bahasa Python.

## 1. Caesar Cipher

Caesar Cipher merupakan cipher substitusi yang melakukan pergeseran
huruf berdasarkan nilai kunci (k).

Contoh:
- Plaintext: ADA RENCANA PENYELUNDUPAN NARKOBA DI BANDARA
- Kunci: 5
- Ciphertext: FIF WJSHFSF UJSDJQZSIZUFS SFWPTGF IN GFSIFWF

File program:
`caesar_cipher.py`

## 2. Vigenere Cipher

Vigenere Cipher merupakan cipher abjad-majemuk yang menggunakan
kunci berupa kata untuk proses enkripsi.

Contoh:
- Plaintext: kriptografiklasikdengancipheralfabetmajemuk
- Kunci: LAMPION

File program:
`vigenere_cipher.py`

## 3. Columnar Transposition Cipher

Columnar Transposition Cipher merupakan cipher transposisi yang
mengubah posisi huruf dalam plaintext dengan membaca teks secara
vertikal berdasarkan panjang kunci.

Contoh:
- Plaintext: sistem dan teknologi informasi itb
- Panjang kunci: 6
- Ciphertext: SDNIAIAONSSNLFITTOOIEEGRTMKIMB

File program:
`columnar_transposition.py`
